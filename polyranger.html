Competitive AnalysisКонкурентный анализ

Why we couldn't just copy one of themПочему нельзя было просто скопировать одного из них

Polymarket, Limitless, and Myriad each solve only part of the task for the audience above — none of them combines market discovery, platform comparison, and native trading in one interface. Below are three direct comparisons, the same screen type, side by side. Polymarket, Limitless и Myriad каждый решают только часть задачи для аудитории выше — ни один не объединяет знакомство с рынком, сравнение платформ и нативную торговлю в одном интерфейсе. Ниже — три прямых сравнения, один и тот же тип экрана, рядом.

Problem: Polymarket's order book requires scanning 40+ rows line by line, digits aren't aligned. Solution: tabular figures (tnum) align probability and volume into columns — the pattern reads in a second, without line-by-line scanning. Проблема: ордербук Polymarket требует построчного сканирования 40+ строк, цифры не выровнены по разрядам. Решение: табличные цифры (tnum) выравнивают вероятность и объём по колонкам — паттерн считывается за секунду, без построчного чтения.

Problem: competitors require filling everything on one screen, with no way to check how the market will look before publishing. Solution: 3 steps with progress and a separate Preview screen before publishing — the error gets fixed before, not after. Проблема: конкуренты требуют заполнить всё на одном экране, без возможности проверить, как рынок будет выглядеть до публикации. Решение: 3 шага с прогрессом и отдельный экран Preview перед публикацией — ошибка исправляется до, а не после.

Key Screens & UX DecisionsКлючевые экраны и UX-решения

The Home Feed with Top Narrative was covered in the "Insight" block above as the case's central solution. Here — the remaining screens that close the full loop: from search to creating your own market. Home Feed с Top Narrative — в блоке "Инсайт" выше как центральное решение кейса. Здесь — остальные экраны, которые закрывают полный цикл: от поиска до создания собственного рынка.

SearchПоиск (Search)

Quick Search modal with two scenarios on one screen — keyword search and category filter. UX decision: search opens as a modal over the page — the user doesn't lose the current screen's context; category tags duplicate the feed filters for fast search without typing. Модалка Quick Search с двумя сценариями на одном экране — поиск по ключевому слову и фильтр по категории. UX-решение: поиск открывается модальным окном поверх страницы — пользователь не теряет контекст текущего экрана; теги категорий дублируют фильтры ленты для быстрого поиска без ввода текста.

Market PageСтраница рынка (Market Page)

30–50 outcomes at once: candidates, price ranges, match results. Each row is a Yes/No probability + volume. UX decision: numeric data uses a separate typographic style with tabular figures (tnum) for column alignment. 30–50 исходов одновременно: кандидаты, диапазоны цен, результаты матчей. Каждая строка — вероятность Yes/No + объём. UX-решение: числовые данные используют отдельный типографический стиль с табличными цифрами (tnum) для выравнивания по колонкам.

Filters & CategoriesФильтры и категории

20+ tags: Politics, Crypto, Sports, Elections, and others. Context switching without leaving the current screen. UX decision: tags are sorted by trading volume, not alphabetically. 20+ тегов: Politics, Crypto, Sports, Elections и другие. Переключение контекста без ухода с текущего экрана. UX-решение: теги отсортированы по объёму торгов, а не по алфавиту.

Create Market FlowФлоу создания рынка (Create Predict Flow)

3 steps + progress indicator. One decision per step. Progress is saved automatically. UX decision: a "Preview" screen before publishing — the user sees how the market will look to others before hitting Publish. 3 шага + прогресс-индикатор. Одно решение на каждом шаге. Прогресс сохраняется автоматически. UX-решение: экран "Preview" перед публикацией — пользователь видит, как рынок будет выглядеть для других, до нажатия Publish.
