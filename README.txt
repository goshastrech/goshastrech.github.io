КАК ОПУБЛИКОВАТЬ ПАПКУ dist/

Что это: готовая к выкладке копия сайта. Внутри только нужные страницы, стили, скрипты и картинки.
Пересобрать после правок в проекте:  bash tools/build-dist.sh  (папка dist/ создаётся заново).

--- Вариант 1. Netlify Drop (самый простой, без аккаунта на 1 час, с аккаунтом — навсегда) ---
1. Откройте https://app.netlify.com/drop
2. Перетащите всю папку dist/ в окно браузера.
3. Через несколько секунд получите ссылку вида https://что-то.netlify.app. Готово.
4. Файл _headers подхватится сам (настройки кэша).
5. Обновить сайт: на странице сайта в Netlify откройте Deploys и перетащите свежую папку dist/.

--- Вариант 2. Cloudflare Pages ---
1. Зайдите на https://dash.cloudflare.com , раздел Workers & Pages, Create, вкладка Pages.
2. Выберите Upload assets (прямая загрузка), придумайте имя проекта.
3. Перетащите папку dist/ и нажмите Deploy.
4. Получите ссылку https://имя.pages.dev. Файл _headers тоже работает.

--- Вариант 3. GitHub Pages ---
1. Создайте репозиторий на GitHub и загрузите в него СОДЕРЖИМОЕ папки dist/
   (index.html должен лежать в корне репозитория, а не внутри подпапки dist).
2. Откройте Settings, затем Pages. В Source выберите Deploy from a branch, ветку main и папку / (root). Save.
3. Через минуту-две сайт откроется по адресу https://ваш-ник.github.io/имя-репозитория/
4. Файл _headers GitHub Pages игнорирует (кэш там настроен сам, на 10 минут) — это нормально.
5. Все пути в сайте относительные (img/..., css/...), поэтому работает и в подпапке репозитория.

Проверка перед публикацией: откройте dist/index.html через любой локальный сервер
(например:  python3 -m http.server 8000 --directory dist ) и пролистайте страницу.
