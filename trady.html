Design a decentralized trading terminal for memecoin traders on web and iOS, and produce everything around the product: the investor pitch deck, graphics and video for social media. CompetitorsКонкуренты

Memecoin traders already have strong platforms: Axiom, GMGN, Trojan and Fomo. For many users, terminals like Axiom feel overloaded and hard to read, while Fomo is simplified so much that there is not enough data to make decisions. Our task was to build a lighter version for people who are tired of, or confused by, trading on platforms like Axiom, but not as stripped down as Fomo: with more data and values that traders can actually use. Трейдеры мемкоинов уже торгуют на сильных платформах: Axiom, GMGN, Trojan и Fomo. Для многих пользователей терминалы вроде Axiom перегружены и непонятны, а Fomo упрощён настолько, что данных для решений не хватает. Наша задача — сделать более лёгкую версию для тех, кому надоело и непонятно торговать на таких платформах, как Axiom, но не такую простую, как у Fomo: с большим количеством данных и значений, которыми трейдеры реально могут пользоваться.

ProcessПроцесс

One design system, built in code with ClaudeОдна дизайн-система, собранная в коде с помощью Claude

I merged three existing design systems into one final system, then rebuilt it in code on the web with Claude. This lets me generate high-quality mockups and hand them to developers quickly, which speeds up the whole process. Я собрал одну финальную дизайн-систему из трёх существующих, а затем воссоздал её в коде на вебе с помощью Claude. Это позволяет генерировать качественные макеты и быстро передавать их разработчикам, что ускоряет весь процесс работы.
